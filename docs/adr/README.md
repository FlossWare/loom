# Architecture Decision Records

ADRs in this repository define decisions about Loom itself.

Implementation-specific decisions belong in the repository implementing Loom unless they change the normative protocol.

Current ADRs:

- 0001: Loom is the language-neutral protocol
- 0002: Serialization and bindings are realization layers
- 0003: Plan is an Implementation
- 0004: Conformance is a first-class deliverable
- 0005: An execution engine is an Implementation
- 0006: Implementation Builder acquisition is part of Loom discovery
